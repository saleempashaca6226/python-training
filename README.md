#Machine Learning Assessment

## Project Overview
This project focuses on predicting loan defaults using machine learning techniques.

The project demonstrates classification, regression, clustering, data preprocessing, feature engineering and model evaluation.

## Dataset
A synthetic loan applicant dataset containing applicant information such as:
- Age
- Annual income
- Employment years
- Credit score
- Debt-to-income ratio
- Loan amount
- Education
- Employment type
- Loan purpose
- Default status

## Machine Learning Techniques

### Classification
- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost

### Regression
- Linear Regression
- Ridge Regression
- Lasso Regression

### Clustering
- K-Means clustering

## Model Evaluation
Classification metrics:
- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix
- ROC Curve and AUC

Regression metrics:
- MAE
- RMSE
- R-squared

Hyperparameter tuning:
- GridSearchCV
- RandomizedSearchCV

## Final Classification Model
Tuned XGBoost achieved the following test results:

- Accuracy: 73.93%
- Precision: 55.81%
- Recall: 30.77%
- F1 Score: 39.67%

## Regression Results
Lasso Regression achieved:
- MAE: 14660.364
- RMSE: 18349.176
- R-squared: 0.318
